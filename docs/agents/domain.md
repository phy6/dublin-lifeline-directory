# Domain Doc Consumer Rules

## Layout

**Single-context** — one `CONTEXT.md` + `docs/adr/` at the repo root.

## Rules

- `CONTEXT.md` is a glossary only — no implementation details, no specs, no scratchpad.
- ADRs live in `docs/adr/NNNN-title.md` format.
- Call the `domain-modeling` skill when changing the domain model.
- `writing-for-agents` skill governs how to write docs agents will read.
