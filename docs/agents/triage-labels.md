# Triage Labels

| Label             | Meaning                                   |
| ----------------- | ----------------------------------------- |
| `needs-triage`    | New issue, not yet categorized            |
| `needs-info`      | Waiting for more information              |
| `ready-for-agent` | Ready to be worked by an AI agent         |
| `ready-for-human` | Needs human review or input               |
| `wontfix`         | Ruled out of scope, will not be addressed |
